# Muxara docs

[Muxara](https://muxara.com) is an online video and audio converter. Upload a file, pick an output format, and download the result.

## MCP

AI agents can use Muxara for programmatic conversion via the [Model Context Protocol](https://modelcontextprotocol.io/). The MCP server exposes the same workflow and limits as the website.

See **[MCP.md](./MCP.md)** for tools, connection instructions (Cursor, MCP Inspector), limits, and a Node.js demo (`pnpm install && pnpm demo`).
